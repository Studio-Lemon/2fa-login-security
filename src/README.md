# Asset Sources

This directory contains editable source counterparts for bundled plugin assets.

## CSS
- `src/css/*.css` maps to versioned files in `css/*.1777414061.css`.

## JavaScript
- `src/js/*.js` maps to versioned files in `js/*.1777414061.js`.

## Current State
- Source files are initially seeded from currently shipped bundles.
- A formal build pipeline has not been introduced yet; these files are the starting point for future unminified cleanup and build automation.
